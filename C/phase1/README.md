## Purpose

Phase 1 is the foundation of my journey into embedded systems engineering.
As a Computer Engineering student actively working toward embedded software
engineering roles in the automotive, aerospace, and IoT industries, I am
building this portfolio to demonstrate real firmware fundamentals to potential
employers.

Each project in Phase 1 targets a concept that appears directly in production
firmware for automotive ECUs, aerospace systems, and bare-metal microcontroller
programming. The simulation approach allows these concepts to be isolated and
understood deeply before applying them on real hardware in later phases.

This portfolio is a document of my growth as an embedded engineer —
from writing a custom memory allocator in pure C to eventually building
complete embedded systems on STM32 and ESP32 hardware.
